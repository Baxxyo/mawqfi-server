# موقفي — خادم التجربة (Mawqfi)

يخدم صفحة الويب ويزامن بين أجهزة صديقاتك لحظياً: مخطط الموقف، البصمات، حالة المواقف، ونتائج الاختبار.

## 1) تشغيل محلي (دقيقتين)

```bash
python -m venv .venv && source .venv/bin/activate      # ويندوز: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn server:app --host 0.0.0.0 --port 8000
```

افتحي http://localhost:8000 للتأكد إنه يشتغل.

## 2) خلي صديقاتك يفتحونه من جوالاتهم

الـGPS بالمتصفح **ما يشتغل إلا على HTTPS**، فلازم رابط https. أسرع طريقة (بدون حساب):

```bash
cloudflared tunnel --url http://localhost:8000
```

(تنزيل cloudflared: https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/)
يعطيك رابط مثل `https://xxxx.trycloudflare.com`. أرسليه لصديقاتك. الجهاز اللي عليه الخادم لازم يبقى شغال طول التجربة.

## 3) نشر دائم (اختياري): Render.com

1. ارفعي هالمجلد على GitHub.
2. Render ← New ← Blueprint ← اختاري المستودع (ياخذ `render.yaml` تلقائياً).
3. بعد النشر تجيك رابط https ثابت.

ملاحظات الخطة المجانية: الخادم ينام بعد فترة خمول (أول فتح يتأخر ~30 ثانية)، وقاعدة البيانات تنمسح عند كل نشر جديد. للتجربة تكفي. لو تبين تحفظ البيانات: أضيفي Persistent Disk وحطي المتغير `DB_PATH=/data/mawqfi.db`.

متغيرات البيئة: `ADMIN_KEY` (اختياري، مفتاح مسح بيانات الجميع)، `DB_PATH`.

## 4) خطة التجربة

1. **وحدة** (تسمّى المشرفة) تفتح تبويب «الاختبار» وتخلي المخطط مثل الموقف الحقيقي (عدد المواقف، الجهات، الأبعاد) وتضغط «طبّق المخطط للجميع».
2. المشرفة تقف بمنتصف الممر باتجاه طوله، تشغل الاستشعار من الخريطة، وتضغط «اضبط الموقف هنا». هذا يثبت المكان والزاوية لكل الأجهزة.
3. **البصمات:** كل وحدة بجهازها تقف داخل موقف، تختاره من تبويب «الاختبار»، تضغط «سجّل بصمة» وتبقى ثابتة 10 ثواني، ثم تطلع. كرروا لين يصير لكل موقف بصمة (أكثر من زيارة أو جهاز = دقة أعلى).
4. **الاختبار:** وحدة تركن بسيارتها بموقف. الباقيات يقفن **برا المواقف** ويراقبن تبويب الخريطة: الموقف لازم يتحول لمشغول لحاله. بعد الركن تختار الراكنة الموقف الفعلي (للقياس فقط، ما يغيّر قرار النظام).
5. **المغادرة:** لما تطلع السيارة لازم يرجع الموقف متاح لحاله (النظام يكتشف الابتعاد عن مكان الركن من الـGPS).
6. جدول «الاختبار وقياس الدقة» يجمع النتائج من كل الأجهزة ويقارن الإطار النظري بالبصمات.

## 5) حدود لازم تعرفينها

- المتصفح ما يشتغل بالخلفية: الشاشة لازم تبقى شغالة والصفحة مفتوحة عند الراكنة.
- ما فيه Activity Recognition بالويب. التفريق بين المشي والقيادة تقريبي (من نمط الاهتزاز)؛ لو نزلت الراكنة ومشت، الموقف يبقى مشغول. النسخة الأصلية لأندرويد أدق.
- الدقة تعتمد على GPS جوالاتكم بالموقف: الأسقف والأقبية تخرّبه. جربوا بموقف مكشوف.
- البصمات من جوال ما تناسب جوال ثاني دايماً، فالأفضل تسجلون بأكثر من جهاز.
- الخادم بدون تسجيل دخول: أي شخص عنده الرابط يقدر يكتب. استخدموه لتجربة مغلقة فقط، ولا تنشرون الرابط.
- البيانات تُخزّن: المخطط والبصمات (إحداثيات) والتقارير ونتائج الاختبار والأسماء المستعارة. احذفوها بعد التجربة من «خيارات المشرفة».
